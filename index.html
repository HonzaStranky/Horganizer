Features

Everything a messy file system actually needs.

01

Organizing

Horganizer sorts files into 15 built-in categories — Images, Videos, Music, Documents (split by PDF, Word, Excel, PowerPoint, Text), Archives, Programs, Libraries, System, Code (by language), Databases, Minecraft, 3D, Books and Games. Anything unrecognized goes to Unknown, not lost.

Made a mistake, or just changed your mind? Restore Files puts everything back.

02

Own Rules

Built-in categories not enough? Create your own rules by extension and destination folder. Rules are checked in order, top to bottom — the first enabled match wins, so you can layer exceptions on top of the defaults.

IF extension = .zip
THEN move to /Archives
IF extension = .psd, .ai
THEN move to D:\Work\Design
Enable Rule
03

Auto Monitoring

Point Horganizer at any folder and it watches it in the background. When a new file appears, Horganizer waits for it to finish writing to disk, then files it away — no clicking required.

04

Duplicates Finder

Scans your chosen folders, groups files by size first, then confirms real duplicates with a SHA-256 hash comparison — so two files are only flagged as duplicates when their content is genuinely identical. Review each group and delete what you don't need.
